# 📦 Supply Chain & Inventory Analytics

A professional Python project for analysing a real-world supply chain and inventory dataset.
The project includes full data cleaning, exploratory analysis, 10 publication-quality charts,
ABC/XYZ classification, stockout and lead-time analysis, and an interactive **Streamlit** dashboard.

---
## Data Source

The dataset used in this project was obtained from Kaggle:

[Kaggle — Supply Chain Dataset](https://www.kaggle.com/datasets/ziya07/high-dimensional-supply-chain-inventory-dataset)

## 🔍 Analysis Performed

### Data Cleaning
- Removed duplicate rows
- Handled missing values
- Enforced correct data types
- Removed records with negative sales, inventory, or zero/negative prices

### Derived Metrics
| Metric                    | Formula                                          |
|---------------------------|--------------------------------------------------|
| Revenue                   | `Units_Sold × Unit_Price`                       |
| Gross Profit              | `Revenue − (Units_Sold × Unit_Cost)`            |
| Gross Margin %            | `Gross Profit / Revenue × 100`                  |
| Inventory Value           | `Inventory_Level × Unit_Cost`                   |
| Inventory Turnover        | `COGS / Avg Inventory Value`                    |
| Days of Inventory (DOI)   | `365 / Inventory Turnover`                      |
| Below ROP Flag            | `Inventory_Level < Reorder_Point`               |
| Forecast Error            | `Units_Sold − Demand_Forecast`                  |

### Analyses
1. **Demand & Sales Trends** — monthly revenue + units, day-of-week patterns
2. **Product Performance** — top SKUs by revenue, gross margin by SKU
3. **ABC Classification** — by cumulative revenue share (A ≤ 70%, B ≤ 90%, C > 90%)
4. **XYZ Classification** — by demand Coefficient of Variation (X ≤ 20%, Y ≤ 50%, Z > 50%)
5. **Inventory Turnover** — ranked best/worst performers
6. **Stockout Analysis** — rates by SKU and warehouse
7. **Supplier & Lead-Time Analysis** — average lead time by supplier, distribution
8. **Revenue by Region & Warehouse**
9. **Promotion Impact** — uplift % per SKU, overall average
10. **Inventory Risk Matrix** — turnover vs DOI, below-ROP frequency

## 🚀 Setup & Usage

### 1 — Prerequisites

- Python 3.9 or later
- pip

### 2 — Install dependencies

```bash
cd supply-chain-inventory-analysis
pip install -r requirements.txt
```

### 3 — Run the analysis (generate charts & tables)

```bash
python analysis.py
```

This creates all files in `outputs/charts/` and `outputs/tables/`.

### 4 — Launch the Streamlit dashboard

```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`.

## 💡 Key Business Insights

1. A small number of Class A SKUs (~20%) drive 70% of revenue — protect their stock levels at all costs.
2. Multiple SKUs regularly fall below their reorder point — immediate replenishment action required.
3. Significant lead-time variance across suppliers creates replenishment risk for fast-moving items.
4. Promotional activity increases average daily units sold — pre-position inventory before campaigns.
5. Several SKUs have very low inventory turnover (< 2×/year), indicating excess stock and high carrying costs.
6. Class Z SKUs with erratic demand need larger safety stock buffers or a min-max replenishment policy.
7. Some warehouses have notably higher stockout rates — investigate whether reorder points are correctly calibrated.
8. Demand forecasts closely track actual sales for X-class SKUs, enabling lean, just-in-time replenishment.

## 📝 Limitations

- The dataset contains synthetic/simulated data; real supply-chain datasets may have additional complexity (e.g. batch orders, partial shipments, multi-echelon inventories).
- Unit costs and prices appear constant per SKU — no cost inflation or price changes are modelled.
- The analysis is at the SKU level aggregated across warehouses and regions; warehouse-level reorder points may differ in practice.
